# 真实使用案例：stock-tool 的 A股黑话省 40~50% token

> 目标：在 benchmark（构造句子）之外，给出「真实项目 + 真实话术 + 真实数据」的证据。
> 素材来源：stock-tool 生产代码里写死的中文话术（**只读取原文，未改动任何生产代码**）。

---

## 核心发现

stock-tool（真实在跑的 A股监控工具）的告警 / 仓位 / 情绪话术，**本身就是 A股黑话**——「放量」「量比」「金叉」「回踩」「低吸」「止损」全是领域术语。这些黑话对比「说人话」，tiktoken o200k 实测省 **39~51% token**。

这说明：**「领域化压缩」不是 demo，真实 A股项目里黑话早就在省 token**。xizi-rujin 的 `/heihua` 档，就是把这种「隐性压缩」产品化——让不会黑话的 agent 也能自动用上。

---

## 案例 1：黑话本身的高密度（真实原文 vs 还原白话）

| 场景 | 黑话（stock-tool 真实原文） | 白话（说人话） | 黑话 token | 白话 token | 黑话省 |
|---|---|---|---|---|---|
| 告警 | `600000 放量 量比3.2（2026-09-30）` | 600000 这只股票今天的成交量突然放大，量比达到了 3.2 倍，日期是 2026 年 9 月 30 日 | 18 | 37 | **51%** |
| 仓位 | `可重仓（6-8 成）：趋势向上，回踩加仓` | 可以采取重仓策略，仓位控制在六成到八成；当前趋势是向上的，可以在回踩的时候加仓 | 17 | 28 | **39%** |
| 情绪 | `情绪冰点，恐慌中孕育机会，可低吸错杀` | 当前市场情绪处于冰点阶段，恐慌之中孕育着投资机会，可以低吸那些被错杀的股票 | 17 | 29 | **41%** |

> 黑话版 = stock-tool 代码里的真实话术；白话版 = 为了对比而做的「说人话」还原（不是 stock-tool 原文）。数字为 tiktoken o200k 实测。

## 案例 2：`/heihua` 把白话自动压成黑话

不会黑话的 agent 写告警，可能说白话：

> 白话：`600000 这只股票今天的成交量突然放大，量比达到了 3.2 倍，日期是 2026 年 9 月 30 日`

xizi-rujin 的 `/heihua` 档（A股黑话词典 50+ 词条），能自动压成 stock-tool 同款黑话：

> 黑话：`600000 放量 量比3.2`

```bash
python -m xizi.cli heihua "600000 这只股票今天的成交量突然放大，量比达到了 3.2 倍"
# 600000 放量 量比3.2
```

## 结论（一句话）

真实 A股项目里，黑话在省 40~50% token；xizi-rujin 把「会黑话」这件事从老股民的隐性技能，变成了任何 agent 都能一键调用的词典。
