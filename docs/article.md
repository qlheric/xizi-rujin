# 中文自带的 token 压缩器：从 ASD-STE100 到「惜字法」

> 一个开源项目的技术复盘：把 caveman 的「受控英语」中文化，做成中文版「省 token」skill，实测省 37.9%，且每一处数字都能复现。

## 一、一个真实摩擦

中文 LLM 场景有个真实的浪费：中文里「的、了、是、很、一、个」这些虚词占了大量 token，但中文又自带压缩基因——单字表意、四字成语、领域黑话。

举个例，同样一句话：

- 白话：`你的 React 组件在重新渲染，原因是每次渲染都创建了新的对象引用，导致 props 变化。`
- 压缩：`组件重渲染，因每渲染新对象引用，故 props 变。`

前者 24 字，后者 17 字，token 省了将近一半，而 `useMemo`、`props`、`O(n²)` 这类关键信息一个没丢。

这个方向开源里不是没人做——caveman（10.9 万星）、ponytail（15.4 万星）都是「省 token」的 meme skill，但它们全是英文的。中文的单字表意、四字成语，是英文做不到的压缩基因。这就是空位。

## 二、站在巨人肩上：caveman 到底做对了什么

很多人以为 caveman 是「让 AI 用原始人语气说话」，其实它的方法学很硬——基于 **ASD-STE100**，一份航空维修领域的受控英语规范：

- **答案先行**，一句一意（20 词上限）
- **意义不丢**：否定词、数字、单位绝不改动
- **payload 原样**：代码、命令、路径逐字符保留
- **工具静默**：工具调用参数不压缩

关键洞察是：**它不是「说话短」，而是「有标准的受控语言」**。没有标准的压缩，就是随机删字，会丢意义。

## 三、把受控语言中文化：五铁律「惜字法」

我把 ASD-STE100 的中文对应物，总结成五条铁律，叫「惜字法」：

| # | 铁律 | 规则 | 例 |
|---|---|---|---|
| 1 | 一字一意 | 双字压单字 | 现在→今 / 因为→因 / 所以→故 |
| 2 | 成语压缩 | 长句压四字 | 「每次渲染都创建新对象」→「每渲染新引用」 |
| 3 | 意义不丢 | 数字、单位、专名、否定词绝不压 | JavaScript ≠ JS |
| 4 | payload 原样 | 代码 / 命令 / 路径逐字符 | `useMemo`、`pip install numpy` 不碰 |
| 5 | 工具静默 | 工具参数不压 | function call 的 JSON 原样 |

这套规则，同时落地成了两层：**人格层**（`SKILL.md`，教 agent 用文言思维压缩）+ **机制层**（一个确定性压缩器，词典 + 规则，可复现、可插拔）。这正好对标 caveman 的「skill + proxy」两层架构。

## 四、诚实 benchmark：为什么我只敢说 37.9%

这一步是跟 ponytail 学的——它最值钱的一条是**诚实 benchmark + 主动纠正夸大**。所以我没写「省 95%」，而是把数字拆开、可复现：

- **分场景**：冗余中文（模拟 agent 真实啰嗦输出）省 **62.4%**，精炼技术句只省 25.6%（英文 payload 必须原样保留，压缩空间天然小）。
- **tokenizer 双轨**：tiktoken o200k 口径省 37.9%，cl100k 口径省 43.2%——不同 tokenizer 下结论稳健，但绝对数字不同，所以我不报单一数字。
- **端到端**：真实 agent（Claude Code）跑 10 个任务用 `/xizi` 压缩，9/10 保真。那 1 个失败是「JavaScript 缩成了 JS」——专名缩写，真实 agent 也会犯，正是五铁律「专名不丢」要防的边界。
- **LLM-judge**：10/10 整体语义保留。

所有数字都能一键复现：

```bash
uv sync
uv run python -m eval.compress_bench     # 压缩率 + 能红断言
uv run python -m eval.semantic_eval      # 语义保真 + 阴性对照
```

这里有两个「可核」的关键设计：

1. **能红断言**：评测里写死了「压缩率必须 ≤0.75」，不达标 CI 直接红、不让发布。
2. **阴性对照**：我故意放了一个「乱删字」的坏压缩器进评测，它必须被抓出来（抓出了 76 个丢失的 payload），证明这个断言是真的能抓错、不是摆设。

## 五、领域化压缩：中文的 23 个压缩基因

caveman 只能压英文。中文的独特优势是**领域黑话**——每个中文圈层都有高密度的术语：

| 领域 | 例 |
|---|---|
| A股金融 | 市盈率→PE、止损卖出→割肉 |
| 互联网大厂 | 关键绩效指标→KPI、调动各部门使行动一致→拉通对齐 |
| 体制内公文 | 深入贯彻落实→落实 |
| 网络流行语 | 永远的神→yyds |
| 二次元 | 动画剧集→番 |
| 医疗 | 急性心肌梗死→心梗 |
| 粤语 | 没有→冇 |

一共 23 个领域、700+ 词条，做成**可插拔词典**——`xizi/glossary/` 下每个文件一个领域，加新领域只需加一个文件，不改核心逻辑。

## 六、踩过的坑（诚实交代）

- **AI 生图对中文不可靠**：做 logo 时，图像模型把「惜字如金」刻成了「中华人民共国万岁」。最后改成手写 SVG 印章，字才保证对。
- **专名缩写的边界**：JavaScript→JS 这种缩写，机器检查和真实 agent 都踩过，所以五铁律第三条明确写了「JavaScript ≠ JS」。
