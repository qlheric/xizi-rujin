# 假绿灯档案（拦截假绿 · 真实案例）

> 每篇四件事：①原来为什么显示通过 ②实际漏了什么 ③哪个验证动作暴露了问题 ④如何修复并防复发。
> 全部是本项目开发过程中**真抓出来**的假绿，不是编的。

---

## ① LLM 复核把「数字答错」洗白

- **原来显示通过**：qwen 评测 150 条带复核后显示 150/150（100%）——因为 LLM-judge 复核把 15 条失败全部判「语义等价」撤销了，包括「鸡兔同笼答 20/15」这种数字答错。
- **实际漏了**：弱模型答错的数字题被 judge 洗白，评测变成"自嗨"（攻击里预言过的「LLM 当评委=自嗨」真实发生了）。
- **暴露动作**：**真红验证**——构造「数字答错」（23/12 答成 20/15），断言复核必须保留失败；复核却判"等价"，当场红。
- **修复**：复核 prompt 加硬规则「数字必须精确一致（23≠32≠12）；只有同义措辞才算等价；解题过程不算」+ 把缺失的 keys 明确传给 judge。

## ② max_tokens=200 截断「详细解题型」模型

- **原来显示失败**：qwen 的数学题全判「缺失关键信息」——看起来是"答错"。
- **实际漏了**：qwen 答对了，只是答案被 `max_tokens=200` 截断在解题过程（"我们来解这个经典的…"），最终答案还没写出来就断了。评测用"截断"冒充"答错"。
- **暴露动作**：**亲验完整答案**——单独调 qwen 看完整输出，发现数字全对、只是被截断。
- **修复**：max_tokens 统一给足（2000/8000），对不同模型的输出风格公平。

## ③ urllib 读 IE 死代理 → 评测全 0%

- **原来显示失败**：deepseek 和 qwen 两个引擎同时 0/200（0%）——看起来像"代码坏了"。
- **实际漏了**：两个 API 都通（直连测试 200 OK），是 Python urllib 读了 Windows 的 IE 代理设置（指向已关闭的代理端口），连接被拒绝。
- **暴露动作**：**双引擎同 0% 的怀疑**——两个互不相干的 API 同时全挂，先怀疑共同代码路径，直连测试定位。
- **修复**：国内 API 直连（`ProxyHandler({})`）、gpt 渠道走代理分路；代码注释写明原因防再犯。

## ④ golden 集的 keys 不在 golden 答案里（28 条）

- **原来显示通过**：mock 自检"好 agent 100%"——看起来 golden 集质量没问题。
- **实际漏了**：medium 28 条的 keys 放了题目术语（幂等/ACID/死锁），golden 答案是解释（不含术语）。之前断言只查"区分度≥60%"不看满分，假象被掩盖。
- **暴露动作**：**满分断言**——把自检改成"好 agent 必须 100%（golden 全通过）"，28 条当场红。
- **修复**：修 28 条 golden；沉淀原则「keys 必须是 golden 里有的核心信息」。

## ⑤ 真弱断言：只测"不崩溃"不测"结果正确"

- **原来显示通过**：`test_all_domains_registered` 是 29 个单测之一，全绿。
- **实际漏了**：它只调 `compress("测试", level)` 不抛异常就过——函数返回错误结果它也不知道。这是「只测不崩溃」的典型弱断言。
- **暴露动作**：**fake_green 静态扫真实 tests/**——检测器在自家测试代码里抓出了这个弱断言。
- **修复**：加断言（`assertIsInstance(compress(...), str)` + 规则数断言）。

## ⑥ 出题错误：1.25×0.8=1 恰好抵消

- **原来显示失败**：hp048「加价 25% 打 8 折仍获利 100」golden=1000，gpt 判"答错"。
- **实际漏了**：题目本身自相矛盾（1.25×0.8=1，利润恒 0，"仍获利 100"不成立）——golden 的 1000 是错的。gpt 反而指出了矛盾。
- **暴露动作**：**手算核 golden**——评测结果和预期不符时，先核题目本身，再判模型。
- **修复**：改题（打 9 折，进价 800）；教训：golden 要手算验证。

## 总教训

**假绿的五种形态**（本档案实证）：①判据自嗨（LLM 洗白）②环境干扰当结论（截断/死代理）③数据自洽性没验（keys 不在 golden）④弱断言（只测不崩溃）⑤题目本身错。

**老审计的三问恰好一一对应**：红过吗（①②判据会红吗）、错的抓得住吗（④⑤阴性对照会抓吗）、挂的那些呢（③⑥失败逐条核过吗）。
